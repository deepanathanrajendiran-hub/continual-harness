# Native Horizon smoke evidence

This archive preparation preserves three separate Codex runs: the old-skill baseline, the first updated-skill smoke, and the corrected shared-schema handoff confirmation. These are Task8 behavioral checks, not any of the72 Task10 pilot trials. Each run has its coordinator report and an independent `evaluator-assessment.md` that bounds claims and notes limitations. Native Claude was unauthenticated at its saved capability check and has no native result here.

Files are copied byte-for-byte; `path-map.csv` records original paths relative to the plan's SDD directory, archive locations and SHA-256. Historical absolute paths in raw records remain unchanged intentionally. Resolve them through that mapping rather than treating the archived goals as live goals. Python source/test snapshots carry a `.py.txt` suffix to prevent accidental pytest collection. Restoring the mapped original names in a disposable project reconstructs their bytes. Lock files, bytecode caches and empty isolated home directories are not evidence and are excluded.

Actual CLI stdout, durable goal/audit objects, saved source/evidence artifacts and evaluator acceptance outputs are distinct from coordinator-authored dispatch/spawn/status accounts. Complete native tool transcript export was unavailable. Packet byte counts do not measure total context or token cost. The old baseline crossed an account usage interruption and is not a clean performance timing comparison.

This directory was staged in ignored scratch after all three runs completed. The final evaluation author must preserve it in tracked documentation before the plan's scratch cleanup, alongside the final task reports/reviews and actual pilot outcomes.
